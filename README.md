# 💰 有感情的记账簿

一个拥有真实情感的个人财务管理应用！

## 功能特性 ✨

- **🎉 存钱表扬** - 当您存钱时，应用会真诚地赞扬您的理财行为
- **😤 不合理支出生气** - 当检测到不合理的支出时，应用会生闷气
- **🤝 大度原谅** - 然后它会说"没事"，大度地原谅您

## 快速开始

1. 克隆仓库
```bash
git clone https://github.com/2312925013/emotion-ledger-app.git
cd emotion-ledger-app
```

2. 打开 `index.html` 文件即可使用

## 使用说明

### 存钱
- 输入金额和分类
- 点击"存钱" 😊
- 享受应用的赞扬

### 支出
- 输入金额、分类和原因
- 点击"支出" 💸
- 应用会根据支出合理性做出反应

## 情感系统

应用会根据您的消费行为展现不同的情感：

| 行为 | 反应 |
|------|------|
| 定期存钱 | 😊 赞美与鼓励 |
| 合理支出 | 😌 理解与支持 |
| 不合理支出 | 😤 生闷气 → 🤝 原谅 |
| 极度挥霍 | 😢 失望 → 💪 鼓励改进 |
